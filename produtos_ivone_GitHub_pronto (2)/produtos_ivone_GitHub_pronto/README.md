# Produtos Ivone — E-commerce Oficial (Campanha Black Friday)

Projeto de loja virtual completa desenvolvido em **HTML5, CSS3 e JavaScript puro (Vanilla JS)** inspirado nos produtos Ivone (*Todo Mundo Odeia o Chris*) e na arquitetura visual de grandes varejistas de beleza (O Boticário, Natura, Avon e Sephora).

## Como Executar
1. Extraia o arquivo `.zip`.
2. Abra o arquivo `index.html` em qualquer navegador moderno (Chrome, Edge, Firefox, Safari). Não requer instalação de dependências ou servidor backend.

## Funcionalidades Incluídas
- **Identidade Visual & Paleta Oficial:** `#641E32`, `#8B344B`, `#D6B77A`, `#F7F1E8`, `#E8D9CC` e `#292326`.
- **Campanha Black Friday:** Descontos reais de até 70% OFF, selos promocionais, preços "De / Por" e cronômetro regressivo.
- **Menu & Espaço Publicitário:** Navegação por categorias com espaço dedicado logo abaixo para marca parceira (*Mercadinho do Doc* com cupom copiável `DOC5OFF`).
- **Produto em Evidência:** Ao clicar em qualquer item, abre modal dedicado com imagem ampliável (zoom interativo) e variação de ângulos/edições.
- **Carrinho & Checkout Completo:** Sacola lateral com barra de frete grátis, cupons (`IVONE10` e `DOC5OFF`), cadastro completo do cliente, cálculo de taxa de entrega e pagamento (PIX com 10% extra, Cartão parcelado ou Boleto).
- **Modo Claro / Escuro e Acessibilidade Inclusiva:** Filtros SVG para daltonismo (Protanopia, Deuteranopia, Tritanopia e Monocromático), intérprete virtual de Libras, notificações 100% visuais e chat escrito para pessoas surdas e mudas.
